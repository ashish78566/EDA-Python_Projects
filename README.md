# 🏨 Hotel Booking Analysis (EDA Project)

## 📋 Overview
Hotel booking cancellations create major challenges for hotel management — affecting revenue forecasting, inventory control, and operational efficiency.  
This project analyzes a dataset containing hotel booking information to uncover the key factors that influence booking cancellations for **City Hotels** and **Resort Hotels**.

## 🎯 Objectives
- Analyze patterns in hotel booking data.  
- Identify factors leading to booking cancellations.  
- Compare behavior between City and Resort hotels.  
- Provide data-driven insights for hotel management and marketing strategies.

## 🧰 Technologies Used
- **Python 3**
- **Pandas** – data manipulation and cleaning  
- **NumPy** – numerical operations  
- **Matplotlib** & **Seaborn** – data visualization  
- **Jupyter Notebook** – analysis environment  

## 📂 Dataset
The dataset used is `hotel_bookings.csv.xlsx`, which contains information such as:
- Hotel type (City or Resort)
- Lead time
- Arrival dates
- Number of adults/children/babies
- Meal type
- Market segment and distribution channel
- Booking status (canceled or not)

> 📎 The dataset can be downloaded from [Kaggle – Hotel Booking Demand Dataset](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand).

## 🔍 Key Steps
1. **Data Loading & Cleaning**
   - Handle missing values and duplicates.
   - Convert data types as needed.

2. **Exploratory Data Analysis**
   - Univariate and bivariate analysis.
   - Visualizations of cancellation trends.
   - Correlation between booking features and cancellations.

3. **Insights & Observations**
   - Identified features most correlated with cancellations.
   - Comparison between City and Resort hotel booking behaviors.
   - Patterns by customer type, seasonality, and lead time.
